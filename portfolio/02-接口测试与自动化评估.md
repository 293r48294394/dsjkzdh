## 三、判定口径（8 问）

结果可断言 / 可重复执行 / 数据可构造可隔离 / 不依赖人工判断 / 契约稳定 / 高频回归或核心链路 / 维护成本低于手工 / 失败可快速定位。

## 六、结论

1. 不追求 100% 自动化：20 条因需 DB 关系、库存/金额口径、产品决策、并发压测或真实验证码环境，留在半自动 / 手工。
2. 安全类（未登录、越权、注入、XSS、幂等）断言明确、构造成本低，优先纳入回归。
3. 数据一致性 / 金额 / 库存类采用「接口断言 + SQL 校验」组合，不强行塞进纯 HTTP 用例。
