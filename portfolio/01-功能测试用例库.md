## 二、用例设计方法

| 方法 | 落地位置 | 举例 |
|---|---|---|
| 等价类划分 | 全模块 | 注册手机号：合法 / 非手机号 / 已注册 / 空 |
| 边界值分析 | 数量、密码、评分 | 购买数量 0 / 1 / 200 / 201；密码 5 / 6 / 16 / 17 位 |
| 场景法 | 交易主链路 | 选购 → 下单 → 支付 → 履约 → 收货 → 评价 |
| 错误推测法 | 异常与容错 | 参数缺失、类型错误、超长内容、负数、并发重复提交 |
| 状态迁移 | 订单状态机 | 未支付发货、未发货收货、取消后付款「复活」 |
| 专项设计 | 非功能 | 性能 60 条 / 安全 56 条 / 兼容 40 条 / 易用性 32 条 |
