## 这个项目里最能说明问题的三个缺陷

- **业务规则可被绕过**：未支付订单能直接发货、未发货订单能直接确认收货 —— 状态机缺少前置状态校验，直接对应资损风险。
- **水平越权**：用他人会话可确认收货、可查看他人订单号 —— 接口层缺少归属校验。
- **并发与幂等**：并发提交订单、并发发货、重复付款 —— 需要幂等键或数据库唯一约束兜底。

## 关于脱敏

本目录的用例与缺陷文档已做脱敏：环境地址替换为占位、账号与密码打码、收货人信息替换为占位符，数据均为测试环境构造数据。

> 框架运行配置 `config/config.yaml` 仍指向本地靶场，便于直接复跑；如需对外演示，建议改为示例值并配合 `db.example.yaml` 的做法。
